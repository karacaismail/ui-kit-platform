## 2. Kapsam

**Kapsamda:** `docs/producers/` altında dört belge.
- `README.md`: ön koşullar ve karar kapıları
- `concierge.md`: üreticiyle elden yayın akışı
- `measurement.md`: ölçüm protokolü
- `community.md`: topluluk kanalı ve geri bildirim döngüsü

**Kapsam dışı:** ürün kodu, hesap, API ucu, yayın hattı, kanalın fiilen açılması, gerçek üreticilerle temas, `data.ts` içindeki parça durumlarının değiştirilmesi, `karar.json` kaydı. `karar.json` kaydını görev sahibi yapar.

## 5. Desen kararı

- **MVVM:** UI yok, bu yüzden kapsam dışı. İleride bu belgeler bir sayfa olarak yayınlanırsa mevcut zincir kullanılır: Markdown okuyucu → adaptör → `FindingsReportViewModel` → View. Yeni bir katman eklenmez.
- **MVC/FastAPI:** HTTP sınırı yok, bu yüzden kapsam dışı. Minimal API kuralı korunur (`AGENTS.md:12`).
- **OOP:** Yeni sınıf ya da servis eklenmez. Testler mevcut saf fonksiyonları (`parseSections`, `findSection`, `parseTable`) ve `RoadmapViewModel` sınıfını kullanır. Kapsülleme sınırı, belgelerin Markdown yapısıyla testlerin beklentisi arasındaki sözleşmedir.
