- **Web'de MVVM:** Yalnız web tarafında. Model saf tiptir. `SnippetViewModel` kaydetme durumunu, geçmiş listesini ve fork etiketini hesaplar ve DOM'dan bağımsız test edilir. View Astro'dur.
